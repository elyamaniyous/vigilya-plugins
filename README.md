# Vigilya plugins

Official assistant connection packages from Genlabs Digital Ltd for Vigilya: accounting audit, risk monitoring and evidence-based investigation.

- `chatgpt/`: ChatGPT plugin package.
- `claude/`: Claude plugin bundle with three French-language skills and the remote MCP connection.

The service endpoint is https://vigilya.io/mcp. A Vigilya account and authorized engagement are required. Onboarding is assisted during the pilot. These packages are submission candidates; directory review and publication are separate steps.
